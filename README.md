## 📱 Overview

**Flutter Auth UI** is the foundation project of the internship series, focused on Flutter fundamentals — project setup, widget hierarchy, layouts, and building clean, reusable user interfaces. It implements four screens commonly found at the start of any mobile app, built with core Flutter widgets and a well-organized folder structure.

**The application includes:**

| | |
|---|---|
| ✨ | Splash Screen |
| 🔐 | Login Screen |
| 📝 | Sign Up Screen |
| 🏠 | Home Screen |

---

## 🎯 Internship Objective

The primary goal of this project is to understand the fundamentals of Flutter development — project setup, widget hierarchy, layouts, and user interface design.

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed and configured

### 1. Clone the repository

```bash
git clone https://github.com/SaudMasood/flutter-auth-ui.git
```

### 2. Navigate to the project

```bash
cd flutter-auth-ui
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```
